# Privacidad de la práctica

La interfaz actual se construye con HTML, CSS e iconos SVG. Las capturas suministradas solo se usaron como referencia visual local; no se sirven como recursos de esta versión ni como fondos de la interfaz.

Los datos del repositorio son ficticios. El nombre, descripción, selección de Private, archivos de ejemplo, mensaje del commit y portapapeles de práctica se guardan únicamente en memoria. Se borran al reiniciar o recargar.

No hay contraseñas, tokens, correos personales, credenciales ni datos de la cuenta que publica el sitio. El nombre Biniac se usa como persona de ejemplo de la interfaz. La URL construida a partir del nombre es una dirección simulada, no una comprobación de que el repositorio exista.

La aplicación no llama a la API de GitHub, no inicia sesión, no abre archivos del equipo, no envía archivos y no modifica el portapapeles del sistema. Solo carga sus propios archivos estáticos, incluido `steps.json`.

El tutorial y los formularios son una simulación educativa. Las acciones de publicación del código en GitHub Pages se realizan por separado del simulador.
