# Revisión de recursos públicos

Se publican únicamente estas cinco capturas del ZIP proporcionado:

- `02_repositorio.png`
- `06_menu_crear.png`
- `07_nuevo_repositorio.png`
- `09_menu_code.png`
- `10_agregar_archivos.png`

Se revisaron visualmente a resolución original. No se observaron contraseñas, tokens, claves, correos personales, notificaciones privadas ni archivos de configuración con secretos. No incluyen la barra de direcciones ni otras pestañas del navegador.

El repositorio visible `Biniac/test` se comprobó mediante una consulta **sin autenticar** a la API pública de GitHub, que devolvió HTTP 200 y `private: false`. Su URL es el ejemplo didáctico que aparece en el portapapeles de práctica.

Las capturas de inicio, navegación y búsqueda (`01`, `05` y `08`) incluyen otros nombres de repositorios cuya visibilidad pública no pudo confirmarse; por eso se excluyeron de la publicación. Tampoco se subió el ZIP ni el resto de imágenes innecesarias. El menú + se practica desde la captura `02`, que no contiene esos nombres.

Los PNG seleccionados se conservan sin alteraciones. Se revisó que no contuvieran metadatos textuales o EXIF adicionales. Las vistas recreadas usan solo texto de ejemplo y nombres de archivos ficticios; no contienen datos de la cuenta autenticada que publica este sitio.

La aplicación no usa servicios externos de fuentes, analítica ni API de GitHub. Solo solicita sus propios archivos estáticos. La selección de archivos y el portapapeles son simulados en memoria; no hay backend, cuentas ni almacenamiento persistente.

Al reemplazar imágenes debe repetirse esta revisión antes de subirlas al repositorio público.
